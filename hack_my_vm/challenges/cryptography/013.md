# Concept 
To identify Vigenere Cipher and how to decrypt it 

# Method of Solve
- Go to the challenge URL and copy the ciphertext
- Since it clearly shows H replaced by M we know that it is some type of substitution cipher which hints to the vigenere cipher
- we go to the cyberchef.io and use vigenere decode to decode using the key
- The Flag is **HMV{VIGNERECYPHER}**
